Procesar varios capítulos en lote

Selecciona varios textos en bruto. La aplicación los procesará uno a uno con el modelo y el prompt elegidos. Los ficheros ESENCIAL son opcionales: selecciona varios y se asociarán por nombre (por ejemplo, bruto prehistoria.docx.md y esencial ESENCIAL_prehistoria.md). Si no hay coincidencia, se avisará y se usará un ESENCIAL vacío.

Caché: el prompt editorial se mantiene como prefijo estable y los datos variables de cada capítulo se envían aparte. Claude usa caché explícita para el prompt; otros proveedores solo reutilizarán ese prefijo si el modelo/API admite caché automática. No se intenta cachear el texto de cada capítulo, porque cambia en cada petición.
