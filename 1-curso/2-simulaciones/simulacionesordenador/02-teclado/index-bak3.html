2. Resumen de modificadores

⇧ Tecla Mayúsculas (Shift)

Sirve para escribir letras mayúsculas y para obtener los símbolos que están pintados en la parte superior de las teclas.

Símbolos comunes con Mayúsculas:

A B C ; : _ ? ¿ $ % & ( )

Alt Gr Tecla Alt Gr

Sirve exclusivamente para escribir el tercer símbolo (el que suele estar abajo a la derecha) en algunas teclas concretas.

Símbolos comunes con Alt Gr:

@ € # \ [ ] { }

3. ¿Qué diferencia hay entre "Alt" y "Alt Gr"?

A los lados de la barra espaciadora hay dos teclas que se llaman de forma parecida, pero hacen cosas completamente distintas:

Alt (a la izquierda)

Significa "Alternativa". Se usa para hacer atajos del ordenador junto con otras teclas. Por ejemplo, si pulsas Alt y F4, se cierra la ventana que tengas abierta. No sirve para escribir símbolos.

Alt Gr (a la derecha)

Significa "Alternativa Gráfica". Como hemos visto, su única función es escribir el símbolo oculto que tienen algunas teclas (como la arroba o el euro).
