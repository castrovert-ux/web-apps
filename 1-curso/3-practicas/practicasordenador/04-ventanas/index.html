Gestión de ventanas en Windows

Todas las prácticas

Guía rápida de ventanas

  • Barra de título: parte superior que suele mostrar el nombre del programa o archivo.
  • Minimizar (—): oculta la ventana sin cerrar el programa.
  • Maximizar (□): hace que la ventana ocupe toda la pantalla.
  • Restaurar (dos cuadrados): devuelve la ventana a un tamaño ajustable.
  • Cerrar (X): cierra la ventana y puede terminar el programa.
  • Alt + Tab: cambia entre ventanas abiertas.
  • Windows + Tab: abre la Vista de tareas.
  • Windows 11: arrastrar una ventana a un lateral o esquina permite organizarla en esa zona.

Guarda tu trabajo antes de cerrar una aplicación. Algunas funciones pueden variar según la configuración del equipo.
