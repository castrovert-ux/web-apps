Explorador de archivos

Todas las prácticas

Guía rápida del Explorador

  • Windows + E: abre el Explorador de archivos.
  • Barra de navegación: muestra ubicaciones como Escritorio, Este equipo y Red.
  • Panel de carpeta: muestra los archivos y carpetas de la ubicación seleccionada.
  • Barra de direcciones: muestra la ruta actual.
  • Barra de herramientas: permite realizar acciones como copiar, pegar y eliminar.
  • Panel de vista previa: puede mostrar una vista del archivo seleccionado si está activado.
  • Copiar: crea otra copia; Cortar y pegar: mueve el elemento.
  • Precaución: practica con una carpeta creada para la clase y no elimines archivos personales.

La apariencia puede variar según la configuración de Windows 11.
