Despliegue en GitHub Pages & Solución CORS

El desafío de CORS en aplicaciones estáticas

Cuando publicas este archivo HTML en GitHub Pages, el navegador bloquea las peticiones `fetch()` directas a cbroadway.net o filmaffinity.com debido a las políticas de seguridad CORS (Cross-Origin Resource Sharing).

Solución Recomendada: GitHub Actions + Cron Job

Para mantener la web 100% gratuita, ultrarrápida y alojada totalmente en GitHub Pages sin necesidad de mantener servidores encendidos, se utiliza un flujo de trabajo automatizado:

  1. Script de Scraping (Python): Se crea un archivo scraper.py que extrae la cartelera diaria de Cines Broadway usando BeautifulSoup o requests.
  2. Matching con FilmAffinity: El script busca cada título en FilmAffinity, extrae la nota media, portada y la mejor crítica, y genera un archivo unificado cartelera.json.
  3. GitHub Action Automatizada: Un archivo de workflow (.github/workflows/update.yml) ejecuta el script en los servidores de GitHub todos los días a las 08:00 AM (usando cron) y actualiza el archivo JSON en el repositorio.
  4. Consumo en el Frontend: Este fichero HTML simplemente realiza un fetch('./cartelera.json') de forma transparente, evitando errores de CORS y garantizando tiempos de carga instantáneos.

Opción alternativa: Microservicio Proxy (Python FastAPI / Cloudflare Worker)

Si prefieres sincronización en tiempo real al cargar la página, se puede desplegar un proxy ligero (gratuito en Render, Vercel o Cloudflare Workers) que añada las cabeceras Access-Control-Allow-Origin: * a las respuestas scraped.
