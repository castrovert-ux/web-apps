Despliegue en GitHub Pages & Solución CORS

El desafío de CORS en aplicaciones estáticas

Cuando publicas este archivo HTML en GitHub Pages, el navegador bloquea las peticiones fetch() directas a cbroadway.net o filmaffinity.com debido a las políticas de seguridad CORS (Cross-Origin Resource Sharing).

Solución Recomendada: GitHub Actions + Cron Job

  1. Script de Scraping (Python): Se crea un archivo scraper.py que extrae la cartelera diaria de Cines Broadway.
  2. Matching con FilmAffinity: El script busca cada título en FilmAffinity y genera un archivo cartelera.json.
  3. GitHub Action Automatizada: Ejecuta el script todos los días a las 08:00 AM y actualiza el JSON en el repositorio.
  4. Consumo en el Frontend: El HTML realiza un fetch('./cartelera.json') sin errores CORS.
